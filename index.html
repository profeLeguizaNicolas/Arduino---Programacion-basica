Arduino.

Programación básica.

La programación en Arduino es una herramienta fundamental para aquellos interesados en la electrónica y el desarrollo de proyectos interactivos. Arduino es una plataforma de hardware libre basada en una sencilla placa con un microcontrolador que permite controlar componentes electrónicos como sensores, motores, luces, entre otros. A través del lenguaje de programación de Arduino, que está basado en C/C++, es posible escribir código que le indica al microcontrolador cómo interectuar con el entorno.


Estructura básica:

En la programación de Arduino, la estructura básica de un programa o sketch esta compuesto principalmente por dos funciones esenciales: setup() y loop(). Estas funciones determinan el comportamiento del microcontrolador y son fundamentales para cualquier proyecto en Arduino 

    void setup (){
    

    }
    void loop(){
    
    }

Sintaxis de la estructura.

Función setup().

La función setup() se ejecuta una sola vez al inicio del programa. Aquí es donde se configuran los aspectos iniciales del hardware, como la configuración de los pines, la comunicación serial o cualquier otro ajuste que el sistema deba realizar antes de empezar a funcionar de forma continua.

Ejemplo: 
     void setup(){
        pinMode( 13, OUTPUT);    // Configura el pin 13 como salida.
        Serial.begin(9600);
    }


Función loop().

La función loop() se ejecuta de manera continua mientras el programa esté en marcha. Aquí es donde se coloca el código que debe ejecutarse repetidamente, como leer sensores, controlar motores, encender y apagar Led's entre otras tareas.

Ejemplo 
    void loop(){
    digitalWrite(13,HIGH);     // Enciende el LED conectado al pin 13.
    delay(1000);    // Espera 1 segundo.
    digitalWrite(13,LOW);      // Apaga el LED.
    delay(1000);     // Espera otro segundo.
    }


Funciones básicas en Arduino.

pinMode(pin,modo)

Configura un pin específico como entrada INPUT o salida OUTPUT.


Ejemplo:
    void setup(){
        pinMode(8,INPUT);    // Configura el pin 8 como entrada.
    }



digitalWrite(pin,valor)

Envía un valor HIGH(alto) o LOW (bajo) a un pin de salida. Esto es comúnmente utilizado para encender o apagar dispositivos como Led's o relés.


Ejemplo:
    void loop(){
        digitalWrite(13,HIGH);    // Envía una señar alta al pin 13.
    }



digitalRead(pin)

Lee el valor de un pin configurado como entrada, devolviendo HIGH o LOW.


Ejemplo:
    int estado = digitalRead(8);    // Lee el valor del pin 8.



delay(ms)

Pause la ejecución del programa por un período de tiempo determinado en milisegundos.


Ejemplo:
    int estado = delay(500);    // Espera 500 milisegundos (medio segundo).



Ejercicios:

  1. Se debe encender y apagar un led utilizando el pin 13 de la placa Arduino. El Led debe encenderse durante un segundo y luego apagarase durante dos segundos.


  2. Un botón conectectado al pin 8 controle el encendido de un led en el pin 13. El led debe encenderse cuando el botón sea presionado y apagarse cuando no lo esté.


  3. Se debe crear un sistema donde un led solo se encienda si dos botones, conectados a diferentes pines, son presionados al mismo tiempo. Si uno o ambos boton no están presionados, el led debe permanecer apagado.


  4. Un led debe parpadear siguiendo un patrón específico: encender durante 500 milisegundos, apagarse durante 300 milisegundos, encenderse nuevamente durante 1000 milisegundos y apagarse durante span.naranja{2000} milisegundos antes de repetir el ciclo.
